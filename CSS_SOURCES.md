# Офіційні джерела для банку CSS

Запитання перевірені за специфікаціями W3C і CSS Working Group. Для кожної теми використані такі модулі:

- Основи CSS: [CSS Syntax Module Level 3](https://www.w3.org/TR/css-syntax-3/)
- Селектори: [Selectors Level 4](https://www.w3.org/TR/selectors-4/)
- Cascade, inheritance, specificity: [CSS Cascading and Inheritance Level 6](https://www.w3.org/TR/css-cascade-6/)
- Box Model: [CSS Box Model Module Level 4](https://www.w3.org/TR/css-box-4/)
- Одиниці вимірювання та функції значень: [CSS Values and Units Level 4](https://www.w3.org/TR/css-values-4/)
- Кольори: [CSS Color Module Level 4](https://www.w3.org/TR/css-color-4/)
- Фон і рамки: [CSS Backgrounds and Borders Level 3](https://www.w3.org/TR/css-backgrounds-3/)
- Typography: [CSS Fonts Level 4](https://www.w3.org/TR/css-fonts-4/) і [CSS Text Level 4](https://www.w3.org/TR/css-text-4/)
- Display: [CSS Display Module Level 4](https://www.w3.org/TR/css-display-4/)
- Positioning: [CSS Positioned Layout Level 3](https://www.w3.org/TR/css-position-3/)
- Flexbox: [CSS Flexible Box Layout Level 1](https://www.w3.org/TR/css-flexbox-1/)
- CSS Grid: [CSS Grid Layout Level 2](https://www.w3.org/TR/css-grid-2/)
- Responsive Design: [Media Queries Level 5](https://www.w3.org/TR/mediaqueries-5/)
- Transitions: [CSS Transitions Level 2](https://www.w3.org/TR/css-transitions-2/)
- Animations: [CSS Animations Level 2](https://www.w3.org/TR/css-animations-2/)
- CSS variables: [CSS Custom Properties Level 2](https://www.w3.org/TR/css-variables-2/)

Загальний стан модулів CSS звірено з [CSS Snapshot 2026](https://www.w3.org/TR/css-2026/).
