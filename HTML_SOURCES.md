# Офіційні джерела для банку HTML

Банк HTML звіряється з нормативними специфікаціями та офіційними рекомендаціями відповідних платформ.

| Тема | Джерела |
| --- | --- |
| Основи HTML, текст, списки, таблиці, форми, семантика, медіа та `head` | [WHATWG HTML Living Standard](https://html.spec.whatwg.org/multipage/) |
| Accessibility | [WAI Forms Tutorial](https://www.w3.org/WAI/tutorials/forms/), [WAI Images Tutorial](https://www.w3.org/WAI/tutorials/images/), [WAI Tables Tutorial](https://www.w3.org/WAI/tutorials/tables/) |
| Основи SEO | [Google Search Central: title links](https://developers.google.com/search/docs/appearance/title-link), [snippets](https://developers.google.com/search/docs/appearance/snippet), [canonical URLs](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) |
| Open Graph | [The Open Graph protocol](https://ogp.me/) |

## Формат банку

- Easy: 4 однорідні варіанти, 1 правильна відповідь.
- Medium: 5 однорідних варіантів, 2 правильні відповіді.
- Hard для «Основ HTML» і «Тексту та базових елементів»: 6 варіантів, 2 правильні відповіді.
- Hard для решти тем: необхідний для відповіді фрагмент коду, 4 однорідні варіанти, 1 правильна відповідь.
